# Agent rules — Kuvexta Odoo Community

- Target branch for Odoo 19 work: `19.0`.
- Preserve upstream copyright, license texts and modification notices.
- AGPL-derived code remains on the Community path; never move or copy it into Professional.
- Prefer upstream-compatible fixes and contributions where practical.
- Do not bundle proprietary vendor source.
- Physical migration must not change a module's license.
- Community modules must not depend on Professional modules.
- Keep provenance explicit for every third-party module and patch.
